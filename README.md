# ASAMU-decomp

[![CI](https://github.com/bailo167/ASAMU-decomp/actions/workflows/ci.yml/badge.svg)](https://github.com/bailo167/ASAMU-decomp/actions/workflows/ci.yml)

**A cross-platform Rust/Bevy engine recreation of *A Story About My Uncle*, based on reverse engineering of a legitimately owned original installation.**

> **Unofficial project.** Not affiliated with, endorsed by, or connected to Gone North Games or Coffee Stain Studios.
> This repository contains **no original copyrighted game assets, code or data**. To use it you will need your own
> legitimate copy of *A Story About My Uncle*; the importer converts data locally from your installation.
>
> **Current state: pre-alpha research. Not playable.**

**Current milestone:** M9 — First original level imported/playable (importer converts textures, meshes and level scenes; player runs original physics, grapple and abilities with recovered values)

## How it works

```
your legitimate original install
        │  read-only
        ▼
static reverse engineering · UE3 package parsing · behavioural observation
        │
        ▼
asamu importer / converter  ──►  user-local converted data  ──►  native Rust/Bevy runtime
```

This is an **engine recreation**: a new runtime that reimplements the game's rules and reads data converted from
your own copy. It is not a mod, a wrapper, an injector or a passthrough of the original executable, and it does not
try to reproduce the original source code. The goal is **behavioural parity**, measured against traces recorded from
the original game.

## Reverse-engineering state

Highlights (full evidence with confidence labels in [`docs/reverse-engineering/`](docs/reverse-engineering)):

- The original Mac executable is an **unstripped** x86_64 Mach-O with ~135k symbols, including local symbols.
  **CONFIRMED**
- All packages share the UE3 tag `0x9E2A83C1`, file version **868**, licensee version **0**. **CONFIRMED** (header bytes)
- `.asamu` is the game's UE3 map extension (`MapExt=asamu`). **STRONG**
- There is no `ASAMU.u` on disk: the cooker merged the ASAMU script package into `Startup.upk`, where package
  `asamu` holds all 172 game classes. **CONFIRMED** (export tables)
- Compression flag 2 is LZO1X; all 42 packages parse and decompress with zero findings, cross-checked by an
  independent implementation. **CONFIRMED**
- The ASAMU native C++ layer is only a settings manager; there is no grapple native code. The player
  (`ASAMUPawn` → `UTPawn` → `UDKPawn`) moves with stock native pawn physics, now specified in
  [NATIVE_PHYSICS.md](docs/reverse-engineering/NATIVE_PHYSICS.md). The grapple is a script weapon
  (`GrappleGun` → `UDKWeapon`). **CONFIRMED**
