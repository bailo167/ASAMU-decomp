# Gameplay evidence database

Rules: never invent constants. Each value cites its source. Confidence: CONFIRMED / STRONG / TENTATIVE / UNKNOWN.

Default values below come from class default objects (CDO, inheritance resolved) and the shipped `.ini` hierarchy.
[`DEFAULTS.md`](DEFAULTS.md) gives the method, and `data/defaults/<Class>.json` gives every value with its defining
class, source and confidence. Behaviour (what the script does with these values) is in [`ABILITIES.md`](ABILITIES.md)
and [`GRAPPLE.md`](GRAPPLE.md). "Pawn+0x…" offsets are native field offsets of the Mac x86_64 build. They are
CONFIRMED by computing the script layout and checking it against 105 offsets cited in `NATIVE_PHYSICS.md` and 1,447
native class sizes (DEFAULTS.md §2).
